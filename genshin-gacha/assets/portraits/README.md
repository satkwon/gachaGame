# Drop real art here

Place a PNG named after an item id and it replaces the generated splash card:

```
yukihana.png   guren.png   yozora.png          (limited 5★)
verena.png     celestine.png   astraea.png     (standard 5★ characters)
celestial_edge.png   embers_requiem.png        (5★ weapons)
mizuki.png  kohaku.png  tsubaki.png  hotaru.png (4★ characters)
whispering_gale.png  ironwood_longbow.png  tidecaller.png
frostguard.png  boulderbreaker.png             (4★ weapons)
travelers_blade.png  hunters_bow.png  apprentice_grimoire.png
iron_point.png  old_maul.png                   (3★ weapons)
```

Portrait orientation, roughly 560×680, looks best. Any valid PNG works.
Ids are the first field of each entry in `../../src/data.rs`.
